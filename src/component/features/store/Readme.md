## Inventory Management
1) First pane is rendered using FeatureContainer>ExplorerContainer>DCExplorerContainer commonly 
2) Second pane is rendered from FeatureContainer>ExplorerContainer>LayoutContainer based on selected node from First pane as below:
    - if NodeType is Site or Inventory then Shows Charts using DashboardChartContainerWithOvelay
    - else if NodeType is Store or Bin then Shows Store and bin data in grid using StoreDataContainer available in this folder
    - else shows Device views if device is selected DeviceViewContainer
